# Fontes de dados

A Fase 1 aceita cadastro manual. Cadastre dados comerciais que você tenha permissão para utilizar, registre apenas informações necessárias e exclua cadastros quando perderem a finalidade comercial.

A pesquisa salva armazena somente critérios. A análise contratual, a escolha do provedor de descoberta, a atribuição e a retenção de resultados entram na Fase 2. Google Places, OpenStreetMap/Overpass, bases públicas, provedores comerciais e importação CSV são candidatos ainda pendentes de avaliação para o uso pretendido.
